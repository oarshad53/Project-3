This repository was developed for the ENGINEER 1P13: Power in Community project. It is a Discord bot that provides object recognition and text reading capabilities, with a visual and audible response.
To use this bot for yourself, enter in your personal Discord bot API key and execute the client class through a terminal. Channel ID's are unfortunately hardcoded, so will need to be changed as necessary.

There is a built-in help command to see how to use this once you get the bot up and running.
